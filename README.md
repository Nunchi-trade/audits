# Nunchi Protocol - Security Audit Report

## Overview

This repository contains security audit reports and analysis for the Nunchi Protocol smart contracts.

## Audit Scope

The genesis vaults audit and remediations can be found at: https://github.com/Nunchi-trade/audits/blob/main/Nunchi_Genesis_Vaults_report.pdf 
This covers the scope of vault deployments associated with nLP. 

The Pendle SY asset for the nLP vault (Hyperbeat) is audited, with remediations and the report found at: https://github.com/Nunchi-trade/audits/blob/main/Nunchi_SY_Token_Review_report%20(6).pdf
